# STM32 LED Heart

An STM32-based embedded project that drives a heart-shaped LED array,
implementing custom LED control and timing logic to create animated
lighting effects.

## Features
- Heart-shaped LED arrangement
- STM32-based LED control
- Custom lighting animations

## Hardware
- Microcontroller: STM32G030K8T6
- LEDs: 16 red LEDs
